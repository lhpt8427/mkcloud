# 跨境专线评测：Mkcloud 全线路套餐价格、延迟参考与选购避坑指南，买前先看这一篇

搜“跨境专线评测”的人，多半卡在同一个地方：同样叫“专线”，有人卖几十块一个月，有人开口就是五百起步，价格差出十倍，谁也说不清钱花在哪。这篇文章以 Mkcloud（mkcloud.net）为例，把它官网当前在售的全部线路、档位和价格逐一整理出来，再把接入限制、退款规则、流量计费方式这些容易踩坑的细节讲清楚，帮你判断这类产品到底适不适合你的业务。

## 先说结论：这类专线不是普通 VPS，别用买 VPS 的思路买它

Mkcloud 是一家 2023 年创建的国人专线服务商，官网定位是“合规跨境电商专线服务器”，交付形态是 VPS：每台机器分配一个独立入口 IP 和一个独立出口 IP，你连入口登录服务器，业务程序在 VPS 内运行，流量从海外出口出去。

三个和普通 VPS 完全不同的点，买之前必须知道：

- **出口不支持外部连入**。它只能“向外访问”，不能用来建站、收邮件、做支付回调或架游戏服务端。如果你的业务需要公网入站，这个产品直接不适合。
- **直连产品绑定省份**。入口只允许你绑定的那个省份的 IP 连入，换城市可以自己切换绑定，但同一时间只有一个省能用。
- **需要实名**。依据《网络安全法》，个人用户要提供手机号、姓名和身份证号，企业用户要提交营业执照等信息。

也就是说，它解决的是一个很具体的问题：给店铺后台、素材上传、直播推流、API 调用这类“从国内主动访问海外平台”的业务，一条稳定、IP 独享的出站通道。拿它当机场用、当建站服务器用，都是买错了东西。

## 共享和独享，到底差在哪、怎么选

这是评测里最容易讲糊涂的部分。Mkcloud 官方说得很直白：**共享和独享区分的是带宽资源和计费方式，不是共享 IP 和独享 IP 的区别**——两类套餐每台都是入口、出口双独享 IP。

共享套餐按“峰值带宽 + 月流量”计费。以沪港入门款为例：1核2G、200Mbps 峰值、1TB 月流量、288 元/月，官网知识库确认过季付 864 元、年付 3456 元，折算下来年付约等于打八折。三个限制要记牢：峰值不保证持续跑满；流量按上行加下行**双向统计**；计量型套餐超量后暂停，需要自助购买流量重置或提工单补差价，IXP 产品则是直接超量停机。

独享套餐按配置带宽计费、不限流量。沪港独享入门 5Mbps 是 650 元/月，听起来比共享贵一倍多，但算一笔账：5Mbps 持续跑满一个月理论流量约 1.6TB，已经超过共享入门的 1TB 额度，而且速率是保证值、不分时段。如果你的任务是长时间稳定传输（备份、数据同步、持续推流），独享更划算；如果是白天偶尔登后台、传传素材，共享的峰值带宽反而更实用。

还有一个常见误区：**不限流量不等于不限速**。独享套餐速度受所购带宽、服务器性能、目标服务限速的约束，买了 5M 独享就别指望跑出 50M 的下载速度。

## IXP 上云入口：最便宜的档位，但有一个前提

对比表格你会发现，同一个方向里 IXP 入口明显更便宜：广港方向广州 BGP 入口 1TB 要 358 元，深圳 IXP 入口 2TB 才 158 元；沪日方向上海电信 1TB 358 元，沪日 IXP 1TB 只要 166 元。

差价来自接入方式。IXP 产品**只允许云厂 BGP 网络连入**，你需要自己有一台符合条件的云服务器当前置，比如阿里云、腾讯云、百度云国内全网，火山云、华为云、UCloud 的部分区域（不同线路支持范围略有差异，下单前看购物车说明）。换算下来，IXP 套餐价格 + 云前置机成本才是真实总成本。

所以选择逻辑很简单：

- 已经有云厂机器的团队，IXP 入口性价比突出，同样预算能买到翻倍的流量和更高的峰值带宽（IXP 档位普遍给到 1~3Gbps 峰值）；
- 从本地宽带直连的，只能选绑定省份的直连款，价格高一些但没有前置机成本；
- 没有云厂机器又想省钱先买 IXP 的——别，普通家宽连不上 IXP 入口，这是官方反复强调的接入限制。

另外 IXP 产品不限连入省份，多地协作的团队只有这一类产品可选。

## 延迟数据怎么看：别拿“3ms”当全程速度

第三方评测里，“广港 3ms 超低延迟”是被引用最多的卖点。这个数字本身没问题——官网资料给出的端内参考就是广港、深港、厦港、泉港 1~2ms，沪港 21ms，沪日 25~28ms，沪美 124~134ms——但它指的是**专线两端的端内延迟**，不是你坐在电脑前 ping 亚马逊后台的数值。完整链路是你本地 → 国内入口 → 跨境段 → 海外出口 → 目标平台，前一段取决于你的宽带，后一段取决于目标平台的位置和路由。

官方知识库给了一套下单后的自测方法，建议照做，既验货也留证据（退款要用）：

1. 用 ping 测本地到入口 IP 的延迟和丢包，白天和晚高峰各测一轮对比；
2. 登录 VPS 后用 mtr/traceroute 观察到目标平台的路径；
3. 用 iperf3 或受控下载测吞吐，iperf3 需要你自有或获授权的服务端。

顺带说一句 IP 质量：有第三方测评提到 Mkcloud 独享 IP 在 Scamalytics 的欺诈检测值为 0，属于比较干净的水平，对做独立站和电商账号的人是个加分项。不过官方自己的口径很克制——出口是服务器 IP，不保证原生、住宅属性或流媒体解锁，独享 IP 也不能保证平台账号不被关联审核。这个边界感反而比某些吹“百分百防关联”的商家可信。

## 购买前必看：计费、退款和升降级的硬规则

这部分是踩坑重灾区，逐条列清楚：

- **实名与付款**：注册用手机号，下单前完成实名认证（个人：姓名+身份证号；企业：营业执照等资料）。支付走支付宝等渠道。
- **开通时间**：现货产品约 1 分钟自动开通；上海 CN2 是稀缺资源，7 天内交付。
- **退款**：**仅支持质量问题退款**，需要在工单里提交具体延迟、速度数据作为证据，由商家审核判断。开通后不支持更换到其他地域。它不是“不满意就退”的试用装，下单前想清楚。
- **升降级**：都要提工单处理，是否迁移、能否保留 IP 以工单结果为准；降级到更低价格套餐时**差价不退**。
- **没有 SLA**：标准套餐默认无服务可用性保证，快照、备份也不在产品能力里，重要数据自己做好备份。需要 SLA 或路由定制要单独议价。
- **优惠码**：官网历史活动码（如 MK-8.8、US-6.9 等）均已过期，官方明确声明仅活动期内有效。当前能用的优惠券要登录后在购物车页面查看，结算时直接抵扣。
- **合规红线**：产品禁止用于机场、回国等用途，违规会被清退且不退款。直连款的白名单省份机制本身也是合规设计的一部分。

## 值不值：按预算和场景给个判断

基于上面核验过的价格，说几个具体判断，不做空泛推荐。

**月预算 200 元以内**：只有 IXP 流量计费产品可选，比如沪港 IXP 2TB（198 元）或沪日 IXP 1TB（166 元），前提是你有符合条件的云前置。这个价位在正规 IEPL/IPLC 市场里属于地板价，对应的是“有云资源、流量中等”的卖家。

**月预算 300~600 元、直连需求**：沪港共享 1TB（288 元）是上海方向最便宜的入门款；广港方向直连 1TB 要 358 元。广东用户如果嫌贵，可以先测深港 IXP 加云前置的组合总成本。

**持续传输、直播推流**：直接看独享带宽。沪日 5M 独享 600 元/月，沪美 5M 独享 800 元/月，广港 5M 独享 500 元/月。带宽档位从 5M 覆盖到 5G，越往上单价越贵，1G 以上基本是企业级预算（万元/月级），普通卖家不用看。

**需要高防**：厦港、泉港是唯二选项，200M 独享 5600~6000 元/月起，默认含 100Gbps DDoS 防护。防护阈值、清洗规则等细节官方未完全公开，有明确防护需求先提工单确认再下单，别只看宣传数字。

**要海外 IP 又要国内优化**：上海 CN2 那款 4500 元/月的产品是特殊定位（上海联通入口+电信 CN2 出口，国内访问优化），注意它不是海外出口，别和沪美、沪日搞混。

最后提醒一句操作层面的事：这类产品按月买试错成本最低，开通当天就把 ping/mtr/iperf3 三项测试做完，留好数据。真遇到质量问题，这些截图就是你工单里唯一的议价筹码。

## 常见问题

**跨境专线一个月到底多少钱？**
看线路和计费方式。Mkcloud 全线月付从 158 元（深港 IXP 2TB）到数万元不等，主流入门档位集中在 158~600 元。只报一个“均价”没有意义，先定方向和流量再比价。

**专线 VPS 和机场有什么区别？**
正规专线 VPS 是独享国际专线上的一台 IDC 服务器，入口出口双独享 IP，需要实名；机场是多人共享的订阅服务，来源和 IP 历史不透明。做电商、广告这类看重 IP 干净度和稳定性的业务，两者不是一类东西。

**能建站、能做游戏服务端吗？**
不能。出口 IP 不支持外部连入，官网在产品页和知识库里反复声明，公开网站、支付回调、邮件接收都要另选支持入站的产品。

**换城市办公怎么办？**
直连款在后台自行切换绑定省份即可，无需重新下单；IXP 款不限省份，只要从支持的云厂网络接入。

**买错了能退吗？**
只有质量问题可退，且要提供测试数据。所以“先买一个月试试”可以，但测试要在开通后尽快做，别拖到快到期才想起来。
